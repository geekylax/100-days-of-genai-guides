# 20 Free Resources That Beat a ₹50,000 AI Course

> @geekylax_ai · 100 Days of GenAI

You don't need to spend ₹50,000 to learn AI — below are 20 free resources, grouped from math foundations to shipping agents, each from a name recruiters actually recognize.

---

## 🧱 Foundations

**📘 Kaggle Learn** — [kaggle.com/learn](https://www.kaggle.com/learn)
Bite-sized, hands-on micro-courses (Python, Pandas, Intro to ML, Deep Learning) you finish in an afternoon, right in the browser. *Beginner.*

**📘 Google Machine Learning Crash Course** — [developers.google.com/machine-learning/crash-course](https://developers.google.com/machine-learning/crash-course)
Google's own fast, practical intro — animated videos, interactive visualizations, and coding exercises covering the core ML workflow. *Beginner.*

**🎥 fast.ai — Practical Deep Learning for Coders** — [course.fast.ai](https://course.fast.ai/)
Top-down teaching: you train a working model in Lesson 1 before diving into the theory, with a famously supportive forum. **Start here:** watch Lesson 1 ("Getting started") and build the image classifier the same day — don't wait until you "understand everything." *Beginner → Intermediate.*

**🎥 Andrew Ng — Machine Learning Specialization (Coursera, audit free)** — [coursera.org/specializations/machine-learning-introduction](https://www.coursera.org/specializations/machine-learning-introduction)
The classic that launched a million careers, rebuilt by DeepLearning.AI × Stanford. Click "Audit" to watch every lecture free (you only pay for the certificate). *Beginner.*

**📘 Khan Academy (Math)** — [khanacademy.org/math](https://www.khanacademy.org/math)
Free, patient drills for the math under ML — algebra, calculus, probability, and statistics — exactly when you hit a wall. *Beginner.*

---

## 📐 Math & Intuition

**🎥 3Blue1Brown — "Neural Networks"** — [youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi)
The visual series that makes backprop and gradient descent finally *click*. **Start here:** watch Chapter 1, "But what is a neural network?" — it reframes everything else you'll study. *Beginner.*

**🎥 StatQuest with Josh Starmer** — [youtube.com/@statquest](https://www.youtube.com/@statquest)
"BAM!" — cheerful, crystal-clear breakdowns of stats and ML concepts (bias/variance, decision trees, logistic regression) one small step at a time. *Beginner.*

**🎥 3Blue1Brown — "Essence of Linear Algebra"** — [youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab)
Vectors, matrices, and transformations as moving pictures instead of formulas — the intuition that makes embeddings and attention make sense later. *Beginner.*

## 🤖 LLMs & GenAI

**🎥 Andrej Karpathy — "Neural Networks: Zero to Hero"** — [karpathy.ai/zero-to-hero.html](https://karpathy.ai/zero-to-hero.html)
Build neural nets — and eventually GPT — from scratch, in code, spelled out line by line, by one of the field's best teachers. **Start here:** do the first lecture, "building micrograd," and type every line yourself; by the end you'll understand backprop better than most ML grads. *Intermediate.*

**📘 Hugging Face — LLM Course** — [huggingface.co/learn/llm-course](https://huggingface.co/learn/llm-course)
The free, hands-on path through Transformers, tokenizers, fine-tuning, and modern LLMs. **Start here:** Chapter 1, then run the `pipeline()` examples in the notebooks before moving on — doing beats reading. *Intermediate.*

**🎥 DeepLearning.AI — Short Courses** — [deeplearning.ai/short-courses](https://www.deeplearning.ai/short-courses/)
Free 1-hour courses built with the companies behind the tools (RAG, agents, prompt techniques, evaluation) — the fastest way to learn one specific skill. *Beginner → Intermediate.*

**🔗 Prompt Engineering Guide (promptingguide.ai)** — [promptingguide.ai](https://www.promptingguide.ai/)
The open reference for prompting — zero-shot, few-shot, chain-of-thought, ReAct, RAG — with a prompt hub and model notes. *Beginner.*

**🔗 Anthropic — Prompt Engineering Docs** — [platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview)
Straight-from-the-lab best practices (be clear and direct, use examples, chain prompts) plus an interactive tutorial you can work through. *Beginner → Intermediate.*

## 🛠️ Build (Agents & RAG)

**📘 Hugging Face — Agents Course** — [huggingface.co/learn/agents-course](https://huggingface.co/learn/agents-course)
A free, structured path through agent theory, design, and real frameworks — with an optional certification. **Start here:** finish Unit 0 (onboarding), create your HF account, then build the first agent in Unit 1 rather than just reading the theory. *Intermediate.*

**🔗 LangChain Docs** — [docs.langchain.com/oss/python](https://docs.langchain.com/oss/python)
The reference for chaining LLMs into apps — tools, memory, retrieval, and agents — with copy-paste quickstarts. *Intermediate.*

**🔗 LlamaIndex Docs** — [developers.llamaindex.ai/python/framework](https://developers.llamaindex.ai/python/framework/)
The go-to framework for RAG: connect your own data to an LLM, build indexes, and query over documents. *Intermediate.*

**📘 Google × Kaggle — 5-Day Gen AI Intensive** — [kaggle.com/learn-guide/5-day-genai](https://www.kaggle.com/learn-guide/5-day-genai)
The self-paced version of the course 140,000+ developers took: foundation models, embeddings, agents, domain LLMs, and MLOps — with daily notebooks. *Intermediate.*

## 🧪 Practice

**🔗 Kaggle Competitions** — [kaggle.com/competitions](https://www.kaggle.com/competitions)
Real datasets, real leaderboards — the single best way to turn tutorials into actual skill (and a portfolio). *Beginner → Intermediate.*

**🔗 Hugging Face Spaces** — [huggingface.co/spaces](https://huggingface.co/spaces)
Deploy and share live ML demos for free — fork an existing Space, study the code, and ship your own app in minutes. *Beginner → Intermediate.*

**📘 Made With ML** — [madewithml.com](https://madewithml.com/)
Goku Mohandas's free, production-grade course on combining ML with software engineering — design, testing, CI/CD, and MLOps — to ship real systems. *Intermediate.*
