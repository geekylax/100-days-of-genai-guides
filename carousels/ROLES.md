# Vibe coder → AI engineer: the jump that pays
- **Vibe coder** — prompts tools, ships fast, shallow. ~₹3–8 LPA / $40–90K (rough; not a real title)
- **AI Engineer** (hot) — RAG, agents, evals, APIs in prod. ₹8–30 LPA / $130–250K+
- **AI Solutions Engineer** — client-facing, builds AI for customers. ₹9–25 LPA / $110–200K
- **ML Engineer** — trains/deploys models, deeper math. ₹8–30 LPA / $130–300K
**Skill checklist to jump vibe coder → AI engineer:** Python fundamentals · RAG (LangChain/LlamaIndex) · vector DBs · writing evals · function-calling/agents · deploying an API · 2–3 shipped projects.
Realistic in 6–12 months. Same tools, up to 5x the pay — the gap is understanding WHY it works.
