# 7 AI projects that get you hired (+ stack)
1. **Chat with your docs (RAG)** — LlamaIndex + a vector DB. The #1 hiring skill.
2. **An agent that does a real task** — tools + function-calling (LangGraph/smolagents).
3. **Fine-tune a small model** — LoRA a 3B model to beat GPT-4 at one job.
4. **An eval harness** — auto-score LLM outputs. Almost nobody builds this.
5. **Multimodal app** — photo → structured JSON (e.g. receipt → expense row).
6. **Deploy a model as an API** — vLLM + a simple frontend. Proves you can ship.
7. **Automate your own boring task** — end-to-end, something you use daily.
Put each on GitHub + a live link. A shipped project beats 10 tutorials.
